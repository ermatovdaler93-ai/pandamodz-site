# PANDA MODZ

Первая версия витрины PANDA MODZ для GitHub Pages.

## Файлы
- `index.html` — структура главной страницы.
- `style.css` — дизайн, адаптация под телефон и компьютер.
- `script.js` — поиск, фильтры, мобильное меню и снег.

## Публикация через GitHub Pages
1. Загрузите все три файла в корень репозитория.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите `Deploy from a branch`.
4. Выберите ветку `main` и папку `/ (root)`.
5. Нажмите Save и дождитесь публикации.

## Важно
Каталог содержит демонстрационные карточки. Замените их описания и ссылки только на свои законные файлы. Проверка Key пока демонстрационная: для настоящей активации нужен серверный backend. Админ-панель в эту версию намеренно не включена.
